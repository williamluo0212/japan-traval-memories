# 投稿功能配置指南（一次性，约 15 分钟）

访客投稿链路：网站上传页 → Cloudflare Worker → GitHub PR → 你合并 = 发布。
代码都已就绪，只差下面三步把你的账号串起来。**令牌和密钥只粘贴到
Cloudflare 的设置里，不要发给任何人（包括 AI 助手），不要写进代码。**

## 第一步：创建 GitHub 访问令牌（PAT）

1. 打开 github.com → 右上角头像 → **Settings** → 左栏最底 **Developer settings**
   → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**
2. 名称随意（如 `goshiki-upload`）；有效期建议 90 天（到期后重新生成粘贴一次）
3. **Repository access** 选 **Only select repositories** → 勾选 `japan-traval-memories`
4. **Permissions → Repository permissions** 只开两项：
   - **Contents：Read and write**
   - **Pull requests：Read and write**
5. 生成后复制令牌（只显示一次），先放着，第二步要用

## 第二步：创建 Cloudflare Worker

1. 登录 dash.cloudflare.com → 左栏 **Workers & Pages** → **Create** → **Create Worker**
2. 名字建议 `goshiki-upload` → Deploy → 点 **Edit code**
3. 把仓库里 `workers/upload-worker.js` 的全部内容粘贴进去，覆盖原有代码 → **Deploy**
4. 回到该 Worker 的 **Settings → Variables and Secrets**，添加：
   | 类型 | 名称 | 值 |
   |---|---|---|
   | Secret | `GITHUB_TOKEN` | 第一步的令牌 |
   | Secret | `TURNSTILE_SECRET` | 第三步会拿到 |
   | Text | `REPO` | `williamluo0212/japan-traval-memories` |
   | Text | `ALLOWED_ORIGIN` | `https://williamluo0212.github.io` |
5. 记下 Worker 的访问地址（形如 `https://goshiki-upload.你的子域.workers.dev`）
6. （可选加固）**Settings → Bindings → KV namespace**：新建命名空间并绑定为
   `RATE`，即启用每 IP 每天最多 5 次投稿的限制

## 第三步：创建 Turnstile 人机验证

1. Cloudflare 控制台左栏 **Turnstile** → **Add site**
2. Domain 填 `williamluo0212.github.io`；Widget mode 选 **Managed**
3. 创建后得到两个值：
   - **Site Key**（公开）→ 填进仓库的 `upload.config.json`
   - **Secret Key**（保密）→ 回到第二步的 Worker，存为 Secret `TURNSTILE_SECRET`

## 最后：填配置并推送

编辑仓库根目录的 `upload.config.json`：

```json
{
  "workerUrl": "https://goshiki-upload.你的子域.workers.dev",
  "turnstileSiteKey": "0x4AAA...（Site Key）"
}
```

提交推送后，网站的「投稿」页会自动从「准备中」变为可用的上传表单。

## 日常审核

有人投稿时 GitHub 会给你发邮件（一个新的 Pull Request）：

- 打开 PR → **Files changed** 预览照片
- **Merge pull request** = 通过，几分钟后网站自动更新
- **Close pull request** = 拒绝，照片不会出现（可顺手删除分支）

## 安全边界备忘

- Worker 已做：20MB 上限、按文件头校验格式（防伪造扩展名）、Turnstile
  人机验证、来源域名检查、可选每 IP 限频
- 令牌权限只覆盖这一个仓库的内容和 PR；泄露时去 GitHub 撤销重发即可
- 任何投稿都必须经你合并才会出现在网站上，没有直接发布的路径
